基本

图片和提示词只保存在消息的扩展数据里并单独渲染，不写进正文，正文 AI 看不到。

画谁（只画一个人）

「自动」= 让解析模型从 {{user}}、当前角色和所有预设里挑本楼的主角。

角色预设（固定部分：发型 / 面部 / 体型 / LoRA）

解析模型（额外模型，读取剧情 → 写服装 / 动作 / 表情 / 神态）

获取模型
Key 保存在酒馆扩展设置里（settings.json），请求时作为请求头经酒馆后端转发。
直接用正文正在用的 API 和模型，会额外占用一次请求。
测试解析模型
解析提示词（高级） 可用变量：{{target}} {{appearance}} {{candidates}} {{last_state}} {{history}} {{latest}} {{floor}}，以及酒馆宏 {{user}} {{char}} 等。

提示词组装

组装模板（高级） 变量：{{trigger}} {{prefix}} {{suffix}} {{appearance}}（固定）＋ {{outfit}} {{action}} {{expression}} {{demeanor}} {{scene}} {{camera}} {{lighting}}（AI）。某一行的变量全为空时整行会被省略。
