配图风格 剧情 / 立绘 / 小说插画 / 漫画（MOSS-Image）· 提示词生成方式
固定外貌 + AI 补充：角色预设的外貌原样放进提示词，AI 只写服装、动作、表情等。AI 写完整提示词：把外貌交给解析 AI，由它写出整段提示词。两种方式都会自动加上最上面的「触发词」、角色的 LoRA 触发词和画风前缀 / 后缀。
漫画模式由解析 AI 按剧情画整页分镜：分几格（不超过上面的格数，1 = 整页一个画面）、每一格的镜头和人物、对话框里的字（用正文里的原话，MOSS-Image 能直接画出中文），再由扩展换算成 MOSS-Image 的 JSON 版面（每一格、每个人、每个对话框的位置）。人物外貌总是由 AI 写进每一格，上面的「提示词生成方式」对漫画不起作用；一楼画一页，「多张图」也不起作用。漫画的输出比较长，「解析模型」的最大输出低于 4096 时，漫画请求自动用 4096。关掉「画对白」= 整页不画任何文字。
打开后，和主角同在这一幕的其他人也可以画进来（最多 3 人），他们的外貌、穿着、位置由解析 AI 按剧情描写，有角色预设的照预设的外貌写。主角的角色 LoRA 会作用于整张图，其他人可能长得像主角。

提示词组装 画风前缀 · 后缀 · 反向提示词 · 模板
动漫模型偶尔会把画面画窄，两边或上下留出白边 / 黑边（像把一张 9:16 的图放在 2:3 的画布中间）。这几个 Danbooru 标签就是描述这种图的，放进反向提示词，画面就会铺满整张图。Anima 模式默认打开；要用 CFG 大于 1 才起作用（Turbo LoRA 的 CFG 1 不行）；正向提示词里写了同样的标签时不加。 解析模型在同一次请求里多写一个 negative 字段：这张图不该出现、容易画错的东西（只有一个人时的多人标签、没穿戴的衣物配饰、还没发生的动作等）。和上面重复的、和正向提示词里一模一样的标签会自动去掉。Anima 模式默认打开；Krea 2 的内置工作流（CFG 1）不使用反向提示词，只对会用到反向提示词的自定义工作流有用。 ComfyUI 会把普通括号当成加权并去掉，Danbooru 标签里的括号（如 artoria pendragon (fate)）就丢了；打开后自动转义，写明权重的 (smile:1.2) 不受影响。

分辨率

和 ComfyUI 的 Resolution Selector 节点一样：宽高 = 像素数 × 1024² 按宽高比分配，对齐到 16 的倍数（例：2:3、1 MP → 832×1248）。打开解析模型选择后，全身图会选竖图、横向场景会选横图，上面的宽高比是它拿不准时的默认值；配图风格自己设了分辨率时以配图风格为准。
