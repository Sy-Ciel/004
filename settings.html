自动配图规则 每隔几楼 · 短回复 · 开场白 · 画图指令
token 数 0 = 不限制，按酒馆当前分词器计算。这两项只影响自动配图：手动生成照常，带 [[ ]] 画图指令的楼层也照常配图；短回复点「继续」写长后会重新判断。 例：她穿上了鞋子 [[red high-heeled shoes]]。发送时括号里的内容从正文里拿掉（正文 AI 看不到），只交给解析模型，优先级最高。消息下方会显示指令，点 ✕ 删除。
图片显示 位置 · 大小 · 保留版本
图片显示在聊天栏旁边空白处的浮动面板里，聊天里只留一个配图条，点它就显示那一楼的图。 拖标题栏移动，拖右下角调整大小，⤢ 放大，▥ 重置到侧边；⌖「跟随阅读位置」开着时，滚动聊天会切到正在看的楼层的图。
图片和提示词只存在消息的扩展数据里，不写进正文，正文 AI 看不到。
角色预设 固定外貌 · 角色 LoRA · 人设绑定 · 渲染配置
绑定用户人设（切换到勾选的人设时，{{user}} 自动使用这个预设）
「默认」= 用「出图参数」里的模型和 LoRA；渲染配置在「渲染配置」一节新建。人设绑定了这个预设时，切换人设会连同模型和 LoRA 一起切换。
配图风格 剧情 / 立绘 / 小说插画 · 提示词生成方式
固定外貌 + AI 补充：角色预设的外貌原样放进提示词，AI 只写服装、动作、表情等。AI 写完整提示词：把外貌交给解析 AI，由它写出整段提示词。两种方式都会自动加上 LoRA 触发词和画风前缀 / 后缀。
打开后，和主角同在这一幕的其他人也可以画进来（最多 3 人），他们的外貌、穿着、位置由解析 AI 按剧情描写，有角色预设的照预设的外貌写。主角的角色 LoRA 会作用于整张图，其他人可能长得像主角。 字段：outfit 服装 / action 动作 / expression 表情 / demeanor 神态 / scene 场景 / camera 镜头 / lighting 光线。
分辨率填 0 = 用「出图参数」里的分辨率。立绘适合竖图（如 832×1216），小说插画适合横图（如 1216×832）。
解析提示词（高级） System 里的 {{output_rules}} 会按生成方式换成时间线、外貌、人物规则和 JSON 输出格式。User 模板可用变量：{{target}} {{appearance}} {{candidates}} {{world_info}} {{fixed_fields}} {{last_state}} {{prev_outputs}} {{history}} {{latest}} {{floor}} {{user_hints}}，以及酒馆宏；没写的块会自动插入。
解析模型 读剧情、写服装 / 动作 / 表情的额外模型 · API 连接
获取模型
会合并进请求体。思考模型（GLM、DeepSeek-R1 等）容易把输出额度用在思考上导致返回空内容，可以在这里关闭思考。Key 保存在酒馆扩展设置里，经酒馆后端转发。
直接用正文正在用的 API 和模型，会额外占用一次请求。
接口偶尔报错（如 Invalid API parameter、429、502）或没返回可用的 JSON 时自动重试；取消、超时、设置填错、输出被截断不重试。GLM 的温度一般要在 0–1 之间。
测试解析模型
解析内容 解析模型能看到什么：剧情 · 之前的配图 · 世界书 · 人设
之前几层楼的解析结果和最终提示词交给解析模型，让人物保持连贯；0 = 不参考。这些记录不在正文里，正文 AI 读不到。
「触发的条目」按剧情关键词试扫描，和正文生成的规则一样，但不会影响正文的粘性 / 冷却计时。
提示词组装 画风前缀 · 后缀 · 反向提示词 · 模板
组装模板（高级） 变量：{{trigger}} {{prefix}} {{suffix}} {{appearance}}（固定）＋ {{outfit}} {{action}} {{expression}} {{demeanor}} {{scene}} {{camera}} {{lighting}} {{others}}（AI）。某一行的变量全为空时整行省略。画面里有其他人物时，「A solo image…」这一行会自动去掉；模板里没写 {{others}} 时自动加在镜头那一行前面。
